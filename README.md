# wali — робот-сборщик мусора на Java

Проект **UBOR-JAVA R02 / WPILib**.

Загрузка полного пакета проекта из подготовленного архива выполняется через GitHub API. Эта начальная запись сама по себе ещё не означает, что все файлы уже загружены.

## Состав пакета

- `cad/`: параметрическая CAD-модель, STEP, чертежи и спецификация механики.
- `electronics/`: проект KiCad, электрические соединения и спецификация.
- `software/`: Java/Maven, Pi4J, DL4J, пульт и модуль WPILib.
- `docs/`: книга PDF/Markdown и инструкции.
- `verification/`: протоколы фактически выполненных проверок.

Инженерный прототип, не готовый к автономной эксплуатации. WPILib включён в исходники R02, но его сборка и выполнение в исходной среде не подтверждены. Готовых обученных моделей машинного зрения нет.
