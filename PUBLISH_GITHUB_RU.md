# Публикация `Eljah/wali`

## Текущее состояние

Этот пакет подготовлен локально. Репозиторий **не создан**, файлы в GitHub **не отправлены**.
GitHub-подключение в чате подтвердило аккаунт Eljah, но не предоставило операций создания/записи;
в рабочей среде не было авторизованного CLI. Запрос `Eljah/wali` вернул 404:
это не доказывает отсутствие репозитория, поскольку он мог быть недоступен подключению.

## Перед запуском

Установите Git и GitHub CLI (`gh`). На Windows доступны команды:

```powershell
winget install --id Git.Git --exact
winget install --id GitHub.cli --exact
```

Откройте новый терминал после установки. Распакуйте ZIP и перейдите в каталог `wali`.
Не добавляйте в него реальные ключи, записи личных данных и пароли перед публикацией.

Выполните вход через браузер именно в аккаунт **Eljah**:

```text
gh auth login --hostname github.com --git-protocol https --web
```

Разрешите настройку аутентификации Git, когда CLI спросит об этом.
Токены и пароль в чат передавать не нужно.

## Windows / PowerShell

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\publish-github.ps1
```

`-ExecutionPolicy Bypass` действует только для этого запуска PowerShell и не меняет постоянную политику.
Сначала ознакомьтесь с текстом скрипта. По умолчанию репозиторий будет **private**.
Для осознанной публичной публикации добавьте `-Visibility public`.

## Linux / macOS / Git Bash

```bash
bash publish-github.sh
```

Для публичной публикации: `bash publish-github.sh public`.

## Что делает скрипт

Проверяет наличие файлов и программ, получает аккаунт через `gh api user` и требует `Eljah`.
При наличии локального `.git` останавливается, не меняя существующий репозиторий.
Создаёт локальную ветку `main`, задаёт имя и noreply-email автора **только в локальной Git-конфигурации**,
добавляет материалы и создаёт первый коммит. Затем вызывает:

```text
gh repo create Eljah/wali --private --source=. --remote=origin --push
```

В конце сравнивает SHA локального коммита и удалённой `main`.
Скрипт не удаляет репозитории, не меняет видимость существующего репозитория и не делает force-push.
Приватность существующего репозитория не изменяется.

## При сбое

При ошибке скрипт завершается. Локальная `.git` может уже существовать; удалённый репозиторий мог быть
создан до ошибки отправки. **Не удаляйте его и не используйте `--force`.** Проверьте:

```text
git status
git remote -v
gh repo view Eljah/wali --json nameWithOwner,url,isPrivate
```

Если подтверждено, что это созданный этим запуском пустой репозиторий, а `origin` указывает именно на него,
после устранения проблемы авторизации достаточно `git push -u origin main`.
Если репозиторий существовал раньше, сопоставьте его содержимое с проектом отдельно; скрипт его не заменяет.
