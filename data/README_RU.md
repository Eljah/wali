# Данные обучения

Реального датасета в R01 нет. PNG, созданные симулятором, — синтетические диагностические кадры, а не обучающая выборка с заявленной точностью.

На этапе объездки Java DatasetRecorder записывает кадры и manifest в явно заданный выходной каталог. Метки предметов задаёт человек. В manifest сохраняются разрешённые контроллером, а не просто запрошенные, линейная и угловая скорости. Примеры файлов разбиения по целым сессиям и bounding boxes находятся в `software/config`.

Сначала собрать независимые поездки, затем разнести целые session_id между train/validation/test, проверить метки и подготовить отдельные ROI для классификатора. Модель движения обучается на полном кадре. Команды подготовки, обучения и проверки приведены в главах 16–19 книги. Соседние кадры одной поездки нельзя случайно перемешивать между обучением и тестом.

Обученных моделей в архиве нет. Их контрольные суммы, статус допуска и согласованные параметры камеры должны оформляться после целевых испытаний.
