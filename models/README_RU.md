# Модели намеренно не подменены заглушками

В комплекте нет обученных весов, полевых фотографий и придуманной точности.
Исходники двух CNN, обучения и проверки — `software/robot-ml`.

Аппаратный режим ожидает `classifier.zip` и `policy.zip` с соответствующими
`*.zip.properties`, создаваемыми `com.ubor.ml.Trainer`.
Преобразование RGB64 NCHW, порядок классов, SHA-256, `kind` и
`approved.for.hardware` проверяются загрузчиком. Trainer записывает
`approved.for.hardware=false`; перевод в true — ручной выпуск после независимой
проверки метрик, локализации, времени получения кадра и работы на стенде.

`--desktop` и `--demo` не используют нейросеть. Их распознавание — oracle из
состояния мира. Для первичного датасета есть `--hardware-teleop` (только камера).
Никогда не обучайте реальную модель на oracle-кадрах с обещанием полевой точности.
